Behind the demo

Meet the AI Agents

Every part of this demo is powered by a small, specialized AI agent. Tap one to try the feature it represents — or peek at what's coming next.

  • Explorer Agent

    Crawls IE program pages and turns them into a structured knowledge base the chatbot can search.

  • Chatbot Agent

    Answers admissions questions in natural language, grounded in the knowledge base.

  • Voice Agent

    Listens to you with Whisper and replies out loud with ElevenLabs — full voice-to-voice chat.

  • Avatar Agent

    Brings answers to life with a HeyGen live avatar that speaks and reacts in real time.

  • Art Designer Agent

    Generates personalized banners with Gemini Nano Banana Pro and 8-second reels with Veo 3.1.

  • Data Analytics Agent

    Tracks every model call, surfaces live token usage and EUR spend across all providers.
  • Coming soon

    Translator Agent

    Multilingual answers and live interpretation so every prospective student can chat in their own language.

  • Coming soon

    Career Coach Agent

    Maps your background to program outcomes and suggests next career moves backed by alumni data.

  • Coming soon

    Application Assistant

    Walks you through admissions documents, deadlines, and scholarships — and checks your draft.

This is a demo interface built on top of public IE Business School content. For official admissions information, visit ie.edu.
